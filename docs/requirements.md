## REQ-001：收藏功能

**用户原始需求：**“用户新的需求，收藏功能。”

**使用场景：**学习者遇到暂时没理解、需要反复复习或经常查阅的内容，希望收藏后能快速找回，不必重复搜索。

**建议首版范围（尚未确认）：**

- 支持收藏和取消收藏术语，状态在列表与详情之间保持一致。
- 提供“我的收藏”入口，可打开收藏内容并返回原来的术语位置。
- 优先复用稳定词条编号保存收藏，词条解释更新后仍能找到同一条内容。
- 如先采用浏览器本地保存，需明确提示保存范围；账号接入和跨设备同步另行设计。

**待确认：**

- 收藏对象仅术语，还是同时包含专题和练习？
- 入口放在速查、画布详情还是共用导航？
- 首版是否只需本机保存；是否需要收藏备注、分组和排序？

**建议验收要点：**

1. 收藏后能在收藏列表找回，重复点击不产生重复记录。
2. 取消收藏后，各入口的状态同步更新。
3. 若采用本地保存，刷新或重新打开同一浏览器后仍保留，清理浏览器数据的影响有明确说明。
4. 内容更新不因标题变化丢失收藏；已失效的编号有提示，不导致页面报错。
5. 不影响现有速查、主题画布、16 个练习及旧链接。

**当前处理：**仅登记需求，未开始实现；与内容校对、专题整理分别推进。

## REQ-002：用向量匹配辅助新旧资料校对

**需求来源：**用户询问 Embedding 模型与向量数据库是否能加快工作，并选择“整理资料：新旧词条自动找相似项”。目标是提高内容整理效率；本次没有要求改造前台搜索。

**建议方案（尚未实现）：**

- 保留名称、缩写和别名的确定性匹配，增加语义相似候选。候选只用于辅助校对，不自动合并或覆盖定义。
- 将名称、语境、定义和必要的通俗说明组成检索文本；保留来源位置、内容指纹、模型版本及编码参数，内容变化时再更新相应向量。
- 可先评测 Qwen3-Embedding-0.6B，多语言能力与规模符合轻量试验方向，尚未在本项目测试，不能承诺质量或速度。
- 当前资料规模较小，先比较本地向量文件与直接相似度计算，不预设需要单独运行向量数据库。资料增长、过滤或多用户更新需求出现后再选库。
- 相似结果输出前若干项及各自语境；同义、不同语境、上下位概念和仅相关关系由校对者裁决。

**小规模验证建议：**构造含中英文别名、相近非同义、同词不同义和无对应旧词的样本，比较当前规则与增加向量候选后的候选召回率、误导候选、实际复核耗时以及编码和检索耗时。速度与质量分开评估，不把高相似度当成事实一致。

**待确认：**是否开始模型试验、使用已部署服务还是独立离线工具，以及资料是否允许发送至云端。未经确认不安装模型或外传原始资料。本地 GPU 推理如获授权，遵守统一调度与总并发 1 的约定。

**参考：**[Qwen 官方模型说明](https://huggingface.co/Qwen/Qwen3-Embedding-0.6B)、[Sentence Transformers 语义检索](https://www.sbert.net/examples/sentence_transformer/applications/semantic-search/README.html)。

**当前处理：**需求已登记；本轮沿用既有校对流程，不启动模型或数据库服务。
